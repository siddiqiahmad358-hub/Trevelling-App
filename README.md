# Wanderly ✈️

**Discover beautiful destinations and plan your next adventure!**

## About the Project

Wanderly is a travel discovery mobile application built using **Expo and React Native**. It allows users to explore travel destinations, view destination details, save their favorite places, and create demo bookings.

The project was created as a learning project to practice React Native and Expo concepts.

## Theme and Concept

- **App Name:** Wanderly
- **Category:** Travel and Tourism
- **Theme:** Travel Discovery
- **Color Palette:** Forest Green, Cream, and Warm Orange
- **Design Style:** Clean, modern, and user-friendly

## Screens

The application includes the following screens:

1. **Welcome Screen** – Introduces users to Wanderly.
2. **Authentication Screen** – Provides demo signup and login.
3. **Explore Screen** – Displays travel destinations with search and category filters.
4. **Destination Details Screen** – Shows destination information and booking options.
5. **Booking Screen** – Allows users to submit a demo booking.
6. **Favorites Screen** – Displays saved destinations.
7. **Profile Screen** – Displays user information and booking details.
8. **Settings Screen** – Includes app settings and logout functionality.

## Installation and Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Start the Expo web server

```bash
npx expo start --web
```

### 3. Open the application

The Expo development server will open the application in your web browser.

## Important Notes

- Authentication is currently for demonstration purposes only.
- User accounts, favorites, and bookings are stored in application memory.
- Data is not permanently saved and may reset when the app reloads.
- No real payment or online booking service is connected.
- Destination images require an internet connection.
